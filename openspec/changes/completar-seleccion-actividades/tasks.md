# Tareas delta: completar-seleccion-actividades

Estas tareas no modifican las 16 tareas históricas.

- [ ] A1. Mostrar una lista o selector de actividades existentes con nombre y estado.
- [ ] A2. Permitir seleccionar una actividad y actualizar `selectedActivityId`.
- [ ] A3. Garantizar que participantes, gastos, balances y pagos mostrados pertenezcan solo a la actividad seleccionada.
- [ ] A4. Seleccionar automáticamente una actividad recién creada y mostrarla con contexto vacío.
- [ ] A5. Presentar actividades cerradas como historial de solo lectura sin implementar reapertura.
- [ ] A6. Verificar que cambiar de actividad no mezcle ni borre datos.
- [ ] A7. Verificar persistencia mediante F5 para actividad seleccionada, estado cerrado y datos históricos.
